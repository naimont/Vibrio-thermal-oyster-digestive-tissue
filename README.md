# Modeling the dynamic heat inactivation of _Vibrio parahaemolyticus_ in oyster digestive diverticula

This repository contains the data, statistical analyses, and modeling workflows supporting the study on dynamic thermal inactivation of _Vibrio parahaemolyticus_ in oyster digestive diverticula. This work is published under the Creative Commons CC BY 4.0 License.
